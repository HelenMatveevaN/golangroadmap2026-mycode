# Async Cron-Like Scheduler in Go

Мини-планировщик задач на Go (Golang), работающий по принципу Cron. 
Проект написан в рамках изучения пакета `time` и конкурентности.

## Особенности
- **Динамический список задач:** можно добавлять новые задачи без изменения ядра планировщика.
- **Асинхронность:** каждая задача запускается в отдельной горутине и не блокирует основной цикл.
- **Потокобезопасность:** добавление задач защищено с помощью `sync.Mutex`.

## Как запустить
```bash
go run main.go
```
