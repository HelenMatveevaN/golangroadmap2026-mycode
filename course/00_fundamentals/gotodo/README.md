# gotodo 🚀

**gotodo** — это быстрый, минималистичный и удобный менеджер задач (CLI To-Do app) для терминала, написанный на языке Go. Программа сохраняет данные в формате JSON, поддерживает цветовое выделение задач, приоритеты, дедлайны и гибкую фильтрацию.

## ✨ Особенности
- **Глобальная доступность**: Установка через `go install` позволяет запускать утилиту из любой папки вашей системы.
- **Цветной вывод**: Автоматическая подсветка статусов, дедлайнов и приоритетов (`HIGH` / `MEDIUM` / `LOW`) с помощью библиотеки `fatih/color`.
- **Идеальное выравнивание**: Таблица выстраивается ровно «в струну» на любом языке благодаря поддержке кодировки UTF-8 и подсчету символов по рунам.
- **Автономное хранение**: Все задачи бережно сохраняются локально в скрытом профиле пользователя (`~/.gotodo/tasks.json`).
- **Умный парсинг**: Поддержка флагов как до, так и после текста задачи.

## 🛠️ Команды и использование

Основной синтаксис:
```bash
gotodo <команда> [аргументы] [флаги]
```

### Доступные команды:
* **`add`**: Добавить новую задачу.
  - Флаг `--priority`: приоритет задачи (`low`, `medium`, `high`). По умолчанию: `low`.
  - Флаг `--due`: дедлайн задачи в относительном формате (например, `2h`, `1d`, `48h`).
* **`list`**: Показать список всех сохраненных задач.
  - Флаг `--filter`: фильтрация списка (`all`, `active`, `done`). По умолчанию: `all`.
* **`done <id>`**: Отметить задачу с указанным ID как выполненную.
* **`rm <id>`**: Удалить задачу из списка по её ID.
* **`clear`**: Полностью очистить базу данных и удалить все задачи.

### Примеры использования:
```bash
# Добавление задач с флагами (порядок флагов не важен)
gotodo add "Срочный багфикс" --priority high --due 2h
gotodo add "Купить продукты" --priority medium --due 1d
gotodo add "Почитать книгу"

# Просмотр задач с фильтрацией
gotodo list
gotodo list --filter active
gotodo list --filter done

# Завершение и удаление задач
gotodo done 1
gotodo rm 3
```

## ⚙️ Установка

1. Склонируйте репозиторий и перейдите в папку проекта.
2. Скомпилируйте и установите утилиту:
```bash
go install .
```
3. Убедитесь, что папка `~/go/bin` добавлена в вашу переменную окружения `PATH` в файле `~/.zshrc` (или `~/.bashrc`):
```text
export PATH=PATH:HOME/go/bin
```
