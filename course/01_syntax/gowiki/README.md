# GoWiki — Статический генератор сайтов на Go

Профессиональный движок для генерации статических сайтов из Markdown-файлов с поддержкой метаданных (Front Matter) и встроенным веб-сервером для предварительного просмотра.

Проект построен по правилам **Чистой Архитектуры** (Clean Architecture) и разделен на изолированные слои (`cmd/`, `internal/`, `pkg/`) [current_time].

## 🚀 Возможности
- 📝 Парсинг **Markdown** в валидный HTML-код (на базе библиотеки `blackfriday`).
- 📂 Поддержка **Front Matter (YAML)** для хранения метаданных статей (автор, заголовок).
- 🎨 Динамические HTML-шаблоны с использованием стандартного пакета `html/template`.
- ⚙️ Гибкая настройка конфигурации через файл `config.yaml`.
- 🕹 Удобный CLI-интерфейс с подкомандами (`serve`, `new`, `build`).
- 🧪 Высокое покрытие core-логики автоматическими unit-тестами (**85.7%**).

---

## 🛠 Установка и запуск

1. Скомпилируйте или запустите проект напрямую через Go:
```bash
go run ./cmd/wiki/
```

### 📋 Примеры использования CLI

#### 1. Создание нового черновика статьи (`new`)
Команда создает пустой `.md` файл с уже заполненными метаданными Front Matter:
```bash
go run ./cmd/wiki/ new MyAwesomeLesson --author "iMac Developer"
```
*Результат:* в корне появится файл `MyAwesomeLesson.md`.

#### 2. Запуск локального веб-сервера (`serve`)
Запускает сервер на порту, указанном в `config.yaml`, для интерактивного просмотра и редактирования страниц:
```bash
go run ./cmd/wiki/ serve
```
После запуска сайт доступен по адресу: `http://localhost:8085/view/TestPage`

#### 3. Компиляция статического сайта (`build`)
Сканирует директорию, превращает все файлы Markdown в чистый HTML и бережно складывает их в папку `public/`:
```bash
go run ./cmd/wiki/ build
```
Готовые HTML-файлы из папки `public/` можно напрямую заливать на любой хостинг (GitHub Pages, Netlify, Vercel).

## ⚙️ Конфигурация (`config.yaml`)
Проект управляется через простой YAML-файл настроек:
```yaml
server:
  port: ":8085"
site:
  title: "Мой Go-Вики Сайт"
  author: "iMac User"
```
